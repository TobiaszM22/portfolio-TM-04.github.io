# Tobiasz Mazur — Portfolio

Prosta, statyczna strona portfolio przygotowana do GitHub Pages. Nie wymaga Reacta, instalowania paczek ani budowania projektu.

## Jak uruchomić lokalnie
Otwórz `index.html` w przeglądarce.

## Jak opublikować na GitHub Pages
1. Utwórz repozytorium na GitHubie.
2. Wgraj zawartość tego folderu do repozytorium (w tym pliki `index.html`, `style.css`, `script.js`, `favicon.svg` oraz folder `.github`).
3. W ustawieniach repozytorium przejdź do **Settings → Pages**.
4. Jako źródło wybierz **GitHub Actions**.
5. Po zapisaniu workflow opublikuje stronę po wysłaniu plików na gałąź `main`.

## Jak edytować
- Teksty: `index.html`
- Wygląd, kolory i układ: `style.css`
- Przełącznik języka: `script.js`
- Kontakt: znajdź adres e-mail i link LinkedIn w `index.html`.

Projekty są przykładowymi koncepcjami portfolio, a nie opisem ukończonych realizacji.
