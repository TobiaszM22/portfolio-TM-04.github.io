# Tobiasz Mazur — Portfolio

Eleganckie, minimalistyczne portfolio web developera. Ciemna kolorystyka, responsywny układ, sekcje projektów, technologii, o mnie i kontaktu.

## Publikacja przez GitHub Pages

1. Rozpakuj ZIP.
2. Wgraj `index.html` do głównego katalogu repozytorium GitHub.
3. Otwórz **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Ustaw gałąź `main` i folder `/(root)`, a następnie kliknij **Save**.
6. Po wdrożeniu otwórz link pokazany w sekcji Pages.

## Przed publikacją

- W `index.html` wyszukaj `twoj.email@example.com` i zamień na swój e-mail.
- Podmień przykładowe projekty na swoje rzeczywiste realizacje. Dodaj linki do demo lub repozytoriów.
- W sekcji technologii zostaw wyłącznie umiejętności, które znasz lub których się uczysz.
- Możesz zmienić monogram `TM.` na własne logo.

## Technologie

- HTML5
- CSS3 (responsywność, animacje hover, preferencja ograniczenia ruchu)
- Bez JavaScriptu, zewnętrznych bibliotek ani procesu budowania

Google Fonts wymagają połączenia z internetem; w razie braku połączenia strona użyje czcionek systemowych.
